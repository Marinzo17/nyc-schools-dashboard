# NYC High Schools Performance Dashboard

Live demo: [https://nyc-schools-dashboard.streamlit.app/](https://nyc-schools-dashboard.streamlit.app/)

## Project Description

An interactive dashboard analyzing SAT performance data across NYC public high schools. This project explores how average math, reading, and writing scores vary by borough, examines the relationship between test participation rates and academic performance, and ranks top performing schools citywide. Built as a hands on practice project to apply data cleaning, exploratory data analysis, and dashboard deployment skills.

## Tools Used

- Python
- Pandas (data cleaning, aggregation, feature engineering)
- Matplotlib (data visualization)
- Streamlit (interactive dashboard interface)
- GitHub + Streamlit Community Cloud (deployment)

## Key Features

- Cleaned missing values in test participation data
- Created a total_score feature combining math, reading, and writing scores
- Grouped and compared average scores across all five NYC boroughs
- Calculated correlation between test participation rate and academic performance
- Interactive borough filter to explore top-ranked schools by region
- Visualizations including bar charts, scatter plots, and boxplots

## Dataset

NYC public high school SAT score data including average math, reading, and writing scores, borough, and percent of students tested.
